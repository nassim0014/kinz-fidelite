# KINZ Fidélité — « Le Code KINZ »

Programme de fidélité digital de la boutique KINZ (Tunis) : carte à tampons sur téléphone,
tamponnée par le personnel via QR code, avec un jeu de niveaux (1 → 50) fondé sur les
nombres premiers et la suite de Fibonacci.
